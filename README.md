## > whoami

I'm **Yash Nayak**, a backend engineer with **3+ years of experience** building scalable applications, secure APIs, real-time pipelines, and data-heavy systems. My background spans Laravel engineering, application security, and AI-augmented development.

I enjoy connecting **backend architecture + security + automation** to turn complex requirements into useful, reliable products.

- ⚙️ **Backend & platform:** PHP, Laravel, Filament, Livewire, REST APIs, queues/jobs, WebSockets and Laravel Reverb
- 🛡️ **Application security:** API security, OWASP Top 10, secure SDLC, and web/API/network VAPT
- 🤖 **AI & automation:** Claude Code, prompt engineering, LLM-integrated workflows, n8n, CI/CD
- 🗃️ **Systems & data:** relational database design, query/index optimization, performance tuning, and high-volume records
- 🧰 **Product integrations:** Stripe, Razorpay, Algolia, Gmail API and Google APIs
